Registration Form

A simple and responsive Registration Form built using HTML, CSS, and JavaScript.
The form is designed to collect participant information such as personal details, academic information, preferred team/role, skills, experience, availability, and social links.

Features
Full Name input
Faculty selection
Academic year selection
Email and phone number validation
College name input
Preferred role selection
Skills and tools section
Relevant experience textarea
Weekly availability selection
LinkedIn profile link
GitHub profile link
Event referral source
Motivation for joining
Required information validation
Consent checkbox
Submit button
Responsive layout

Technologies Used
HTML5 – Structure of the registration form
CSS3 – Styling and responsive design
JavaScript – Form submission and validation
